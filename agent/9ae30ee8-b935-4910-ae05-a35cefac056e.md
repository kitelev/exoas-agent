# agent__Instruction_order — место инструкции в промпте

Целое число: порядок, в котором сборщик ставит инструкции на место маркера `<!-- exo:instructions orders=A-B -->` в персоне бота (по возрастанию; маркер с диапазоном забирает инструкции с порядком внутри диапазона).

У глобальных инструкций порядок **обязателен** — его отсутствие сборщик считает ошибкой сборки (`minCount` намеренно не объявлен: у правил пользователя порядка нет, они идут по времени создания).
