# agent__Instruction — инструкция агенту

Текст, который становится частью **системного промпта** агента (Telegram-бота над Экзокортексом). Тело ассета — сам текст инструкции; метка — заголовок раздела в промпте.

## Кто исполняет

Сборщик системного промпта в демоне бота (`scripts/olya-assistant/bot_instructions.py`, вызывается из `poll_assistant.py` перед каждым ходом модели). Персона бота несёт служебные строки-маркеры `<!-- exo:instructions orders=A-B -->`; сборщик ставит на место маркера инструкции, адресованные этому боту, по возрастанию `agent__Instruction_order`, и подставляет имя обёртки бота вместо `{exo}`.

## Модель доверия

Инструкция — текст системного промпта, поэтому источник ограничен:

1. глобальные инструкции берутся **только** из ассетспейса `kitelev/exoas-bot-instructions`, который в бот-vault'ах работает как зеркало GitHub (режим ExoSync «только чтение»: локальная правка затирается до сборки);
2. правила пользователя («запомни правило») — только из папки анкера правил **внутри собственного репозитория бота** и только после подтверждения кнопкой «Принять».

Инструкция того же класса в любом другом ассетспейсе в промпт не попадает.

## Архив и вытеснение

`exo__Asset_archived: true` или `exo__Asset_deprecatedBy` — сборщик инструкцию пропускает («забудь правило» = `apply archive`).
