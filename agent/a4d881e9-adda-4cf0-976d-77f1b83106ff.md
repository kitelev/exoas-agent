# agent__Instruction_appliesTo — кому адресована инструкция

Агенты (боты), которым адресована инструкция. **Нет значения — инструкция для всех ботов**, читающих ассетспейс, где она лежит; есть значения — только для перечисленных.

Range — `agent__Agent` (а не `bot__TelegramBot`): иначе `$agent` зависел бы от `$bot`, а `$bot` уже зависит от `$agent`. Экземпляры подклассов агента (в том числе Telegram-боты) проходят проверку диапазона.
